# Data Dictionary

One row represents one synthetic customer; customer_id is unique.

| Column | Type | Definition |
|---|---|---|
| customer_id | Text | Synthetic customer key. |
| tenure_months | Integer | Months with the service. |
| contract_type | Category | Month-to-month, One year, Two year. |
| internet_service | Category | Fiber, DSL, No internet. |
| monthly_charges_inr | Decimal | Synthetic monthly charge in INR. |
| total_charges_inr | Decimal | Synthetic cumulative charges. |
| support_tickets_90d | Integer | Support tickets in the previous 90 days. |
| late_payments_12m | Integer | Late payments in the previous 12 months. |
| payment_method | Category | Electronic check, Bank transfer, Credit card, Digital wallet. |
| autopay_enabled | Yes/No | Automatic payment setting. |
| senior_citizen | Yes/No | Synthetic demographic flag for segmentation practice. |
| churned | Yes/No | Synthetic churn label generated by deterministic rules. |

All records are synthetic. Churn labels depend on contract type, tenure, support, late payments, autopay and charges; segment differences are partly built into the generator and are not causal findings.
