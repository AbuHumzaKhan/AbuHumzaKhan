# Customer Churn & Retention Analysis

Portfolio case study using PostgreSQL SQL, Excel reporting, and Power BI assets. Dataset is synthetic and contains 800 curated customers; raw data has 808 rows including duplicates and data-quality issues. Overall synthetic churn rate is 33.6%. Month-to-month churn is 58.0%, one-year churn is 13.3%, and two-year churn is 3.1%. These differences are partly encoded by the synthetic label rule and are not causal findings.

See the SQL files, data dictionary, and Power BI model guide in this folder. The Excel workbook is available as a downloadable artifact in the project delivery but is not committed because this connection cannot upload binary files.
